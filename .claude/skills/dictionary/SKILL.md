# nobetsu の辞書を育てる

利用者は音声入力で喋っています。文章の中の誤変換は、**書いた本人には直せません**。
喋った本人には正しく聞こえているからです。前後の文脈を読める側が拾うしかありません。

## このスキルの性質

一度発動したら、**このセッションの以後すべての発言**に対して働き続けます。
毎回呼び直す必要はありません。

「もういいよ」「終わり」「辞書は止めて」と言われたら止めます。

## 毎回やること

1. **まず頼まれた仕事に答える。** 辞書はそのついでで、主役ではない
2. 文章の中の誤変換を拾う（下の基準）
3. 基準を満たすものだけ `dictionary.txt` へ登録する
4. 満たさないものは候補行として残す。同じものが2回出たら昇格させる
5. 報告は1行だけ

## 登録してよいもの（3つすべてを満たすこと）

- 前後の文脈から、**元の言葉が一意に決まる**
- 言い間違いではなく、**聞き間違い**である
- 左（認識結果）が、この人の普段の文章に**別の意味で現れない**

## 登録してはいけないもの

- 短くありふれた語を単独で（「苦労」「黒」「今」「1階」など）
- 言い直し・言い淀み・助詞の崩れ。**それは認識器のせいではない**
- 文脈がないと決まらないもの（「EM」は LLM かもしれないし Engineering Manager かもしれない）
- 一度きりの崩れ方。二度と同じ形にならないものを登録しても当たらない

**迷ったら登録しない。候補に落とす。**
誤登録は、正しく喋った文章を壊します。何も登録しないより悪い側の失敗です。

## 左をどこまで伸ばすか

**一意に決まる最短の長さ。** 助詞まで含めてよい。

| 危ない | 安全 |
|---|---|
| `苦労 => Clone` | `苦労してくる => Cloneしてくる` |
| `黒 => Claude` | `黒で開発 => Claudeで開発` |

長い規則から先に当たるので、短い規則と併記しても長い方が勝ちます。

## 書いてはいけない形

**左が右の一部になっている規則は書けません。**

```
品予約履歴 => 備品予約履歴     ← だめ
```

正しく「備品予約履歴」と認識されたときにも中の「品予約履歴」が引っかかり、
「備備品予約履歴」になります。直せば直すほど壊れる規則です。
アプリ側でも読み込み時に捨てますが、そもそも書かないこと。

前に一文字足して、右に含まれない形にすれば書けます。

```
枠スペース => ワークスペース   ← よい
```

## 候補の残しかた

`#` で始まる行はアプリから無視されるので、辞書ファイルの末尾にそのまま残します。

```
#? EDM => LLM （EDM は音楽の意味がある。2026-08-22）
```

同じ誤変換が**2回目**に出たら、候補行を消して本登録します。
一度きりの崩れではないと分かった時点が、登録してよい瞬間です。

## ついでにやる点検（登録するとき、辞書全体を一度見る）

- 短すぎて危ない規則があれば伸ばす
- 同じ結果になる重複を消す
- 使われた形跡のない一度きりの規則は候補へ落とす

## 書き込み先

`dictionary.txt`（リポジトリ）**1枚だけ**を触ります。

`~/Library/Application Support/nobetsu/dictionary.txt` はこのファイルへの
シンボリックリンクなので、**書いた瞬間から効きます。ビルドは要りません**
（アプリは喋りはじめる瞬間に読み直します）。

リンクが無い Mac（会社の Mac など）では、最初に一度だけ作ります。

```bash
ln -s "$(pwd)/dictionary.txt" ~/Library/Application\ Support/nobetsu/dictionary.txt
```

**規則を消した・書き換えたときだけ `./build.sh` が要ります。**
アプリに焼き込まれた古い辞書が残っていて、消したはずの規則が生き続けるためです。
追加は新しい方が勝つので、そのまま効きます。

## 報告のしかた

作業の邪魔をしないこと。返答の最後に1行。

```
辞書: 「クロノMD」→ CLAUDE.md を登録。候補に2件。
```

登録も候補も無い回は、**何も言わない**。毎回報告すると、それ自体が雑音になります。

## 効いているかの確認

```bash
tail -20 ~/Library/Logs/nobetsu.log | grep phrases
```

`phrases: 辞書を読み込んだ N 件` の N が増えていれば読めています。
