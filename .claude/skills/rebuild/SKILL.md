# nobetsu を作り直して動かす

コードを変更したら、この手順を最後まで通してください。
途中で止めると、古いアプリが動いたままになり、直したはずの挙動が確認できません。

## 0. 署名できるかを先に見る

```bash
./build.sh --check
```

`✅ 証明書「nobetsu」で署名できます` なら先へ進みます。

`❌` の場合、**ここで止めて利用者に報告してください。**
証明書は利用者にしか作れません（キーチェーンアクセスの操作と、キーチェーンのパスワードが要る）。
出力に作り方がそのまま載っているので、それを伝えます。

**この確認を飛ばさないこと。** 証明書が無いままビルドするとアドホック署名になり、
入力監視が**ダイアログすら出ずに拒否**されます。⌘ の長押しに一切反応しないアプリができあがり、
しかも利用者からは理由が見えません。別の Mac へ移したときに実際に丸一日溶かしています。

## 1. ビルドして入れ替える

```bash
./build.sh
```

`/Applications/nobetsu.app` に設置されます。

- `==> signing (nobetsu)` と出れば署名は固定されています。許可はやり直しになりません
- `✋ 中止しました` で終わった場合は証明書がありません。**設置もされていません**（0. に戻る）
- `NOBETSU_ALLOW_ADHOC=1` は、コンパイルが通ることだけ確かめたいときの逃げ道です。
  **動作確認には使えません。**利用者に頼んで動かしてもらう前に、これを使わないこと

エラーが出たら、ここで止めて内容を報告してください。

## 2. 起動し直す

```bash
pkill -f nobetsu.app
```

```bash
open /Applications/nobetsu.app
```

`open` だけでは駄目です。既に動いている場合、新しく起動せず
古いものを前面に出すだけなので、変更が反映されません。

起動してもウィンドウは出ません。メニューバーの波形アイコンだけが目印です。

## 3. ログで状態を確かめる

```bash
tail -20 ~/Library/Logs/nobetsu.log
```

**ここまで確かめて初めて「入れ替わった」と言えます。**起動が成功していれば、
最後に近い行に次が出ます。この行が無いなら、アプリは動いていても何も見張っていません。

```
trigger: 見張りを開始した
```

同じ場所に出る `bootstrap:` の行で、版と署名も確かめられます。

```
bootstrap: v<VERSION の中身> / 入力監視 CG=granted HID=granted / 署名 dev.pochang6.nobetsu 安定した署名
```

- 版が上げたはずの数字と違う → 入れ替わっていません。2. をやり直す
- `署名 ... adhoc(TCC に嫌われる)` → 0. からやり直す。許可は下りません

代わりに次が出ていたら、許可が足りていません。

```
trigger: イベントタップを作れない（入力監視=... アクセシビリティ=...）
```

その場合は `false` になっている側の許可が必要です。
アプリが自動で要求ダイアログを出し、メニューバー（警告の三角）にも
何が足りないか・どの設定を開けばよいかが出ます。利用者に許可してもらってください。
**入力監視が下りるまで、アクセシビリティの要求へは進みません**（順番を入れ替えると
入力監視の要求そのものが通らなくなるため）。入力監視で止まっているのに
アクセシビリティの話をしないこと。

## 4. 利用者に確認を依頼する

自動で確かめられるのはここまでです。実際に喋る操作は利用者にしかできません。
何を試してほしいのかを、変更点に対応させて具体的に伝えてください。

例：
- 「⌘ を長押しして喋り、文字が入るか」
- 「喋りながら Enter を押し、余計な文字が残らないか」
- 「ESC で止めたあと、遅れて文字が入らないか」
- 「止めたあと、macOS 標準の音声入力（Fn キー）が正常に動くか」

## 不具合を調べるとき

**推測で直す前に、必ずログを読んでください。**

```bash
tail -40 ~/Library/Logs/nobetsu.log
```

このプロジェクトでは、ログを入れずに推測で修正を重ねて半日を失いました。
ログを入れた直後に原因が一発で判明しています。

ログに手がかりが無い場合は、**まず該当箇所にログを足して、
もう一度再現してもらう**のが最短です。修正案を並べるより速く終わります。

症状ごとの見どころは CLAUDE.md の「よくある調査」にまとめてあります。
